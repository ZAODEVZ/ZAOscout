ZAOscout

Read Reddit, X (including long-form Articles) and Farcaster from the command line. No API keys, no OAuth, no login, no browser.

Get it on GitHub

Try it

git clone https://github.com/ZAODEVZ/ZAOscout.git && cd ZAOscout
./setup.sh
scout doctor
scout https://farcaster.xyz/dwr.eth

What it reads

  • Reddit: title, author, body and the comment tree.
  • X: tweet text, media and the full Article body.
  • Farcaster: casts, embeds, profiles and recent casts.
  • GitHub: commits, releases, issues and discussions.

Three ways to use it

A CLI, an MCP server for AI agents, and an HTTP API. It runs on your machine, or free on GitHub Actions with a daily digest.
